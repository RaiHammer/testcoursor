# DanForge get-reviews — инструкция по программе

Программа собирает отзывы **Яндекса** (Карты и поддерживаемые страницы Яндекс Магазина), формирует сниппет `danforge_reviews_yandex.liquid` и (опционально) загружает его в тему магазина. Отзывы **InSales** виджет получает сам через Liquid prefetch — CLI их не генерирует.

**Запуск:** дважды кликнуть `start.bat` (CustomTkinter) или `python gui_ctk.py` из папки `cli`.  
Legacy ttk-интерфейс: `start_ttk.bat` / `python gui.py`.

---

## Общая схема работы

```
1. Настроить клиента (магазин + API + Яндекс)
2. Проверить API
3. Сгенерировать + загрузить → danforge_reviews_yandex.liquid
4. На сайте обновить главную — виджет подтянет Yandex + InSales prefetch
```

Повторять шаг 3 раз в месяц или по запросу клиента.

---

## Левая панель — «Клиенты»

У каждого магазина свой профиль в папке `cli/clients/<имя>/`.

| Элемент | Что делает |
|---------|------------|
| **Список клиентов** | Выбор магазина. Во второй строке — статус последнего запуска и дата. |
| **+ Добавить** | Создать нового клиента (пустой шаблон настроек). |
| **Обновить** | Перечитать список и статусы с диска. |

**Статусы в списке:**
- `ok` — последний запуск успешен
- `dry-run` — был тестовый прогон без записи файлов
- `error` — ошибка (см. журнал внизу)

При первом запуске старый `config.json` из папки `cli` автоматически переносится в `clients/`.

## Поля настроек (правая часть)

### Подключение к магазину

| Поле | За что отвечает | Пример |
|------|-----------------|--------|
| **Название клиента** | Подпись в списке слева. На работу не влияет. | `ArmedF Demo` |
| **Магазин** | Адрес inSales **без** `https://` | `myshop.myinsales.ru` |
| **API key** | Ключ из админки: Приложения → Разработчикам | длинная строка hex |
| **API password** | Пароль к ключу (не пароль от входа в админку!) | |
| **ID темы** | Какую тему править. Пусто = опубликованная тема. | `10935393` или пусто |

Где взять API: **Настройки → Приложения → Разработчикам → Создать ключ доступа**. Нужны права на отзывы и редактирование темы.

### Отзывы Яндекса

| Поле | За что отвечает |
|------|-----------------|
| **URL Яндекс (Карты или Магазин)** | Ссылка на страницу с отзывами. См. таблицу ниже. |
| **Файл отзывов Яндекса (опц.)** | Запасной вариант: JSON-файл вручную, если парсер не сработал. Кнопка `...` — выбор файла. |

#### Какой URL Яндекса выбрать

| URL | Источник | Сколько отзывов | Когда использовать |
|-----|----------|-----------------|-------------------|
| `yandex.ru/maps/org/.../reviews/` | Яндекс **Карты** | Все доступные (SSR + `?page=2`, при необходимости Playwright) | **Рекомендуется** для большинства магазинов |
| `reviews.yandex.ru/shop/domain.ru` | Яндекс **Магазин** | До ~31 с текстом (API `/ugcpub/digest`) | Если на сайте нет организации на Картах; счётчик «87» на витрине ≠ число отзывов в API |

> **Яндекс Магазин:** кнопка «Показать ещё» на сайте подгружает те же данные, что CLI уже забирает через digest. Остальные отзывы на витрине часто из **отзывов на организацию** (Карты) — их даёт только URL Карт.

> **Playwright** для shop-URL не используется — эффект тот же, что у digest. Для armedf.ru: Maps 70/70, Shop 31/31.

### Что попадёт в Yandex-сниппет (генерация)

| Поле | За что отвечает | Рекомендация |
|------|-----------------|--------------|
| **Yandex limit (0 = все)** / `yandex_limit` | Сколько Yandex-карточек записать в сниппет. 0 = все найденные. | `20` |
| **Мин. рейтинг (1–5)** | Отзывы ниже этой оценки **не попадут в файл** при генерации. | `4` или `5` для главной |

> **Режим источника:** CLI всегда работает в режиме `yandex` — генерирует только Yandex-сниппет. InSales собирает виджет.

> **Программа vs виджет:** CLI фильтрует при **генерации Yandex-сниппета**. InSales фильтруется в **виджете** (Liquid + настройки `min_rating`, `hide_insales`). Лимиты показа по макету — в настройках виджета (`slider-limit`, `page-size` и т.д.). См. `artifacts/2026-07-13-reviews-load-limits/05-report.md`.

## Галочки (чекбоксы)

| Галочка | Когда включать |
|---------|----------------|
| **Загрузить в тему** | После генерации файл уходит в сниппет `danforge_reviews_yandex.liquid`. Для обычной работы **оставляй включённой**. |
| **Dry-run** | Тест: покажет сколько отзывов нашлось, **но не создаст файлы и не загрузит** в магазин. |
| **Приоритет с аватаром** | При выборе отзывов в слайдер чаще попадут те, у кого есть фото. |
| **Playwright** | Запасной браузерный парсер. Нужен только если SSR и пагинация `?page=2` не дали все отзывы или Яндекс вернул 0. |

## Кнопки — первая строка

| Кнопка | Что делает | Когда нажимать |
|--------|------------|----------------|
| **Сохранить** | Записывает поля в `clients/<имя>/config.json` | После любых изменений настроек |
| **Проверить API** | Проверяет ключ и пароль, показывает название магазина и список тем | После первой настройки или смены API |
| **Тест Яндекса** | Только проверяет: сколько отзывов видит парсер по URL Яндекса | Если Яндекс даёт 0 отзывов |
| **Сгенерировать** | Создаёт файлы в `output/`, **без** загрузки в тему | Если хочешь сначала посмотреть файл |
| **Сгенерировать + загрузить** | Генерация **и** загрузка сниппета в тему | **Основная кнопка** для обновления отзывов |

---

## Кнопки — вторая строка

| Кнопка | Что делает |
|--------|------------|
| **Все клиенты** | По очереди обрабатывает **всех** из списка слева (с учётом галочек «Загрузить» и «Dry-run»). |
| **Копировать сниппет** | Копирует `output/danforge_reviews_yandex.liquid` в буфер — если автозагрузка не сработала, вставить вручную в Snippets темы. |
| **Открыть output** | Открывает папку с готовыми файлами текущего клиента. |
| **Планировщик…** | Подсказка: как настроить ежемесячный автозапуск через Планировщик заданий Windows (`install_scheduler.bat`). |
| **Демо** | Создаёт 3 тестовых отзыва без API — для проверки виджета. |
| **Справка** | Открывает этот файл. |

## Журнал (внизу)

Сюда пишется ход работы: сколько отзывов найдено, куда сохранён файл, успешна ли загрузка в тему, текст ошибок.

Типичные сообщения:
- `inSales: 0` — в магазине нет опубликованных отзывов (добавить в админке: Товары → Отзывы)
- `Яндекс: 70` — парсер нашёл 70 отзывов (при необходимости догружает `?page=2`, `?page=3` для SSR-страниц)
- `Сниппет обновлён` / `Сниппет создан` — загрузка в тему прошла успешно

## Типовые сценарии

### Первый запуск для нового магазина

1. **+ Добавить** → ввести название
2. Заполнить магазин, API key, password, URL Яндекса
3. **Сохранить**
4. **Проверить API**
5. Убедиться, что в теме есть сниппет `danforge_reviews_yandex.liquid` (программа создаст при первой загрузке)
6. **Сгенерировать + загрузить**
7. Обновить главную страницу магазина

### Ежемесячное обновление одного клиента

1. Выбрать клиента слева
2. **Сгенерировать + загрузить**
3. Готово

### Обновление всех клиентов разом

1. **Все клиенты** (галочка «Загрузить в тему» включена)

### Проверка без изменений на сайте

1. Включить **Dry-run**
2. **Сгенерировать** или **Сгенерировать + загрузить**
3. Смотреть журнал
4. Выключить Dry-run

## Программа и виджет — кто за что отвечает

| Задача | Где настраивать |
|--------|-----------------|
| Какие Yandex-отзывы **собрать** (рейтинг, количество) | **Программа (CLI)** |
| InSales-отзывы на сайте | **Виджет** (Liquid prefetch + AJAX) |
| Как **показать** (макет, вкладки, лимиты слайдера) | **Виджет** inSales |
| **Загрузить** данные в магазин | **Программа** |
| Заголовок, ссылка «Оставить отзыв» | **Виджет** в админке inSales |
| Сколько карточек **на экране**, автопрокрутка, цвет | **Виджет** |
| Обрезка длинного текста, «Читать полностью» | **Виджет** (`text-lines`) |
| Выравнивание текста отзыва | **Виджет** (`review-text-align`) |
| Скрыть кнопку «Оставить отзыв» | **Виджет** (`hide_write_btn`) |
| Блок товара под рейтингом (InSales) | **Виджет** (авто из meta отзыва) |
| Sticky-отступ floating-кнопок | **Виджет** (`floating-offset`) |
| Страница товара: только отзывы товара | **Виджет** gen-4 (`product.reviews`, вкладка «Товар») |
| Gen-2 магазины (шаблон generation 2) | **Виджет** `projects/df_reviews_slider_gen2/` (Yandex-only; тот же CLI-сниппет) |
| Скрыть отзывы с низким рейтингом **на сайте** без перегенерации | **Виджет** (фильтр отображения) |

После изменений в **программе** — снова «Сгенерировать + загрузить».  
После изменений только в **виджете** — достаточно сохранить настройки виджета в админке.

## Ошибки

| Проблема | Что проверить |
|----------|----------------|
| Ошибка 401 | Неверный API key или password |
| Ошибка 404 на shop | Опечатка в поле «Магазин» |
| Яндекс: 0 | URL организации, кнопка «Тест Яндекса»; для Shop — попробовать URL **Карт**; запасной JSON-файл |
| Shop: меньше, чем на витрине | Лимит API Магазина (~31 с текстом); использовать `yandex.ru/maps/org/...` |
| Не удалось загрузить сниппет | Права API на тему; «Копировать сниппет» → вставить вручную |
| На сайте старые отзывы | Сделать «Сгенерировать + загрузить», обновить страницу с Ctrl+F5 |
