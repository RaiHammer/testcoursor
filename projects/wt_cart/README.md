# Динамичная корзина — виджет inSales (DanForge)

**Handle:** `danforge_dynamic_cart`  
**Автор:** [DanForge](https://danforge.ru) — сертифицированный партнёр inSales

Боковая панель корзины (desktop) / bottom sheet (mobile) с обновлением без перезагрузки страницы.

## Возможности

- Автооткрытие при добавлении товара в корзину
- Динамическое обновление состава через EventBus inSales
- Отображение вариантов (размер, цвет и др.)
- Изменение количества, удаление позиций
- Промокод
- Итоговая сумма
- Переход к оформлению заказа
- Адаптив: панель справа (ПК) / шторка снизу (мобильные)

## Установка

1. В админке inSales: **Настройки → Виджеты → Создать виджет**
2. Загрузить файлы из архива: `info.json`, `settings_form.json`, `snippet.liquid`, `snippet.js`, `snippet.scss`
3. Добавить виджет в **список outside** (вне шаблона) на всех страницах
4. В шапке сайта повесить на иконку корзины вызов:

```javascript
// Пример: onclick или через data-атрибут
window.openCartModal && window.openCartModal();
```

5. Заполнить настройки в админке виджета:
   - Заголовок корзины
   - Заголовок при добавлении товара
   - Текст кнопки оформления
   - Копирайт / доп. текст внизу

## Требования

- inSales, generation 4 widget
- Тема с поддержкой EventBus и стандартного Cart API
- Рекомендуется для магазинов одежды и аксессуаров

## Настройка цветов

По умолчанию: чёрная кнопка, белый фон. Для смены цветов отредактируйте `snippet.scss` или закажите кастомизацию у DanForge.

## Маркировка автора

- Handle виджета: `danforge_dynamic_cart`
- Комментарии в `snippet.liquid`, `snippet.js`, `snippet.scss`
- Атрибут `data-danforge-widget` на корневом элементе
- Копирайт внизу корзины настраивается в админке (по умолчанию — ссылка на danforge.ru)
