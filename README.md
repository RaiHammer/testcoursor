# Личный джарвис — ИИ-команда DanForge

ИИ-команда для развития бизнеса DanForge: сайт danforge.ru, поиск клиентов, разработка продуктов и рост дохода.

## Миссия

| Направление | Фокус |
|-------------|-------|
| **Сайт danforge.ru** | SEO, контент, дизайн, конверсия, портфолио |
| **Поиск клиентов** | Каналы, офферы, воронка, Kwork, партнёрства |
| **Разработка продуктов** | Виджеты inSales, SaaS, шаблоны, инструменты |
| **Доход** | Метрики, приоритизация, ретроспективы |

## Команда (11 ролей)

Вы → **Jarvis** (ассистент) → специалисты. Полный список ролей — в [AGENTS.md](AGENTS.md).

## Режимы работы Jarvis

1. **Операционный** — конкретные задачи (SEO, виджет, правка, дизайн)
2. **Стратегический** — совещания, проработка идей без немедленного исполнения
3. **Ретроспективный** — анализ периода, новый roadmap (раз в 1–2 месяца)

## Как начать

**Памятка владельца:** [knowledge/owner-playbook.md](knowledge/owner-playbook.md) — все сообщения = Jarvis (`@` опционален).  
**Профиль владельца:** [knowledge/owner-profile.md](knowledge/owner-profile.md) · анализ [artifacts/2026-07-27-owner-analysis/](artifacts/2026-07-27-owner-analysis/)

```
@jarvis Создай виджет inSales для фильтра — полный цикл
@jarvis Давай обсудим новые продукты для inSales
@jarvis Ретроспектива за последние 2 месяца
@jarvis Составь план работ на ближайшие 2 месяца
```

**inSales-виджеты:** перед разработкой — `knowledge/platforms/insales-widgets.md`, перед отдачей — `templates/insales-widget-checklist.md`.

## Структура проекта

```
.cursor/agents/     — subagents (роли команды)
.cursor/rules/      — правила оркестрации + owner-interaction
.cursor/skills/     — навыки и workflow (13 skills)
knowledge/          — база знаний (стратегия, метрики, owner-playbook)
templates/          — шаблоны артефактов
artifacts/          — результаты работы по задачам
projects/           — кодовые проекты
scripts/            — test-widgets.sh (CI локально)
```

## Особенности danforge.ru

Сайт на **Tilda** — код недоступен. Команда работает в режиме «анализ → рекомендации → ручное внесение в Tilda».
