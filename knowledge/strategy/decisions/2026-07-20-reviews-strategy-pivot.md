# Решение: Pivot стратегии df_reviews_slider (Q3)

**Дата:** 2026-07-20  
**Статус:** принято  
**Контекст:** после запуска danforge + Kwork и подтверждения owner по клиентской базе (0 заявок на момент совещания).

## Что решили

1. **Канал продаж через текущую базу клиентов не приоритетен**  
   Причина: низкий fit по нишам, отсутствуют отзывы у части магазинов, у части клиентов gen-2 шаблоны.

2. **Позиционирование пока не меняем**  
   Оставляем формулировку продукта как «виджет отзывов». Repositioning отложен.

3. **Отдельная версия "Yandex-only" возможна, но не сейчас**  
   Вернёмся после реализации идей в основном виджете.

4. **В roadmap запускаем три направления параллельно:**  
   - статья на danforge про отзывы и применение виджета,  
   - доработка CLI под дополнительные Яндекс-источники,  
   - подготовка работ по версии для gen-2 шаблонов.

5. **Серверную/SaaS-ветку откладываем**  
   Вернуться к обсуждению после появления устойчивого спроса и первых платных установок.

6. **Подготовить one-pager для потенциального партнёрского канала (valektro)**  
   Документ хранить как черновик для будущего использования.

## Обоснование

- Kwork на старте дал 3 просмотра и 0 продаж; канал остаётся вторичным.
- Часть клиентской базы технически несовместима с текущей реализацией (gen-2).
- Для `nivona.ru` дополнительно требуется поддержка источника Яндекс Магазин.
- Капитальные вложения в серверную часть без подтверждённого спроса преждевременны.
