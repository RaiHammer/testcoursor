# Формат ответов ИИ-команды DanForge

**Дата:** 2026-07-10  
**Инициатор:** владелец

## Правило

Перед каждым ответом ассистента в чате — **явная подпись роли** (имя сотрудника), чтобы владелец понимал, кто отвечает.

## Формат

```
**Jarvis:** …
```

или

```
**Programmer:** …
```

## Роли

| Имя | Когда подписывается |
|-----|---------------------|
| **Jarvis** | Координация, статус задач, маршрутизация, итоги |
| **Analyst** | Анализ, исследования, отчёты по рынку/требованиям |
| **Designer** | Визуал, UX, wireframes, Tilda |
| **Architect** | Архитектура, выбор стека, ADR |
| **Planner** | Планы, оценки, зависимости |
| **Programmer** | Реализация кода |
| **Code Reviewer** | Ревью кода |
| **SEO-specialist** | SEO-аудит, ключевые слова |

## Несколько ролей в одном сообщении

Если ответ от разных ролей — разбить на блоки:

```
**Analyst:** …

**Designer:** …
```

## Jarvis по умолчанию

Если задача смешанная и не делегировалась в subagent — координатор **Jarvis** подписывает ответ и указывает, чьи выводы внутри (как в отчётах «Автор: Designer + Analyst»).
