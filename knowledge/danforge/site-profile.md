# Профиль danforge.ru

## Основное

| Параметр | Значение |
|----------|----------|
| URL | https://danforge.ru |
| Платформа | Tilda (код недоступен, только просмотр через браузер) |
| Создан | Сентябрь 2025 |
| Ниша | Разработка и поддержка интернет-магазинов на inSales |
| Статус | Официальный сертифицированный партнёр inSales |

## Услуги

1. **Создание интернет-магазина** — запуск за 7–14 дней
2. **Переезд на InSales** — миграция с сохранением SEO и данных
3. **Модули и решения** — готовые и кастомные виджеты
4. **Техническая поддержка** — реакция до 2 часов
5. **Портфолио** — кейсы (mardo.world, olaola.store, prettycosmetics и др.)

## Целевая аудитория

- Владельцы интернет-магазинов на inSales
- Бизнес, планирующий переезд на inSales
- Компании, нуждающиеся в доработках, виджетах, интеграциях

## Ключевые преимущества (УТП)

- Сертифицированный партнёр inSales
- Скорость и качество без задержек
- Поддержка 24/7
- Опыт 9+ лет в ecommerce (отзывы клиентов)

## Ограничения для ИИ-команды

- **Нельзя** редактировать код сайта напрямую
- **Можно:** SEO-аудит через браузер, рекомендации по контенту и дизайну, инструкции для ручного внесения в Tilda
- **Программист** работает только с отдельными проектами (виджеты, скрипты), не с Tilda

## Уточнения от владельца (июль 2026)

- **Два hero-блока** на главной — намеренно: один для ПК, один для мобильных (ограничение Tilda для адаптива). Это не дубль контента.
- **JSON-LD** внедрён на главной и ключевых страницах. Validator: Organization, WebSite, Service, FAQPage — 0 ошибок.
- **Бесплатный аудит** как лид-магнит — не использовать (часто геморрой или клиенту нужна полная переделка).
- **Яндекс.Директ** — не останавливать: прямых конверсий мало, но трафик + часть клиентов связались напрямую.

## Разделы сайта

- Главная (hero, партнёрство inSales, портфолио, услуги)
- Страницы услуг (создание, миграция, модули, поддержка)
- Портфолио / кейсы
- Статьи (блог)
- Отзывы
- FAQ
- Форма заказа / обратной связи

## Каналы привлечения (текущие)
