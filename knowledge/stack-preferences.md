# Предпочтения по стеку

## Основной профиль

- **Роль:** фронтенд-разработчик
- **Специализация:** inSales (виджеты, Liquid, интеграции), корпоративные сайты

## Языки и фреймворки

| Область | Предпочтение |
|---------|--------------|
| Frontend | TypeScript, React (приоритет), Vue — по задаче |
| Стили | CSS Modules, Tailwind — по проекту |
| InSales | Liquid, JavaScript виджеты, API платформы — **см. `knowledge/platforms/insales-widgets.md`** |
| Тесты | Vitest, Jest — unit; Playwright — e2e при необходимости |
| Сборка | Vite, Next.js — по проекту |

## Принципы разработки

- Минимальный diff — не рефакторить без запроса
- Функциональные компоненты, хуки для переиспользуемой логики
- Явная обработка ошибок, без пустых catch
- Без секретов в коде (.env, credentials.json)
- Следовать существующим конвенциям проекта
