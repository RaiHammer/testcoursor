## Блок 4. Возможности (8 пунктов)

## Блок 9. FAQ

**Подойдёт ли моей теме inSales?**  
Нужна тема inSales generation 4. Напишите URL магазина — проверим до заказа.

**Откуда берутся отзывы?**  
О товарах — из вашего магазина inSales (живые, с подгрузкой). О компании — подтягиваем с Яндекс Карт по ссылке на вашу организацию.

**Нужен ли сервер или API у меня?**  
Сервер вам не нужен. Для пакета Стандарт желателен API-ключ inSales. Если API нет — пакет Manual: мы работаем через доступ в админку.

**Чем Manual отличается от Стандарта?**  
Manual — для тарифов inSales без REST API. Состав виджета тот же (все источники, все макеты), но установка и обновления идут через админку силами DanForge. Цена выше на 2 000 ₽ разово.

**Сколько макетов можно использовать?**  
Все шесть входят в оба пакета: slider, masonry, grid, list, spotlight, marquee. Для главной рекомендуем slider или сетку; masonry с «Показать ещё» — для страницы отзывов или блога.

**Нужна ли отдельная страница отзывов?**  
Для слайдера, сетки и бегущей строки — нет. Для masonry с подгрузкой InSales сверх первой порции — нужна страница с пагинацией отзывов (например блог shop-reviews) или мы настроим prefetch до 50 отзывов без кнопки «Загрузить ещё».

**Как часто обновляются отзывы с Яндекс Карт?**  
В рамках сопровождения — регулярно, по графику DanForge. Разовое обновление вне пакета — по договорённости.

**Можно только inSales без Яндекса?**  
Нет — виджет всегда рассчитан на оба источника. Если профиля в Яндекс Картах пока нет, поможем настроить блок под доступные отзывы.

**Лицензия на один магазин?**  
Да, одна установка — один интернет-магазин. Переезд на новый домен — +3 000 ₽.
