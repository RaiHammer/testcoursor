# Полный отчёт: danforge.ru — история, результаты, аудит

**Дата:** 6 июля 2026  
**Подготовлено:** ИИ-команда «Личный джарвис» (Jarvis + Analyst + SEO)  
**Для:** Даниил, основатель DanForge

---

## 1. Резюме для владельца

За ~10 месяцев существования сайта (с сентября 2025) вы построили **рабочий B2B-актив**: узкая ниша inSales, партнёрский статус, 8 статей, 10+ кейсов, 6 отзывов, страницы услуг с баннерами, профиль в каталоге inSales и на Kwork.

**Главный результат бизнеса:** с апреля по июнь 2026 пришла волна клиентов — это совпало с работой над сайтом, Kwork и, вероятно, рекомендациями. Сейчас июль — сезонный спад, но **~8 клиентов на поддержке** — это стабильная база.

**Главная проблема сайта как канала:** мало органического трафика по коммерческим запросам; реклама в Директе на периоде апр–июл дала 0 конверсий. Сайт **лучше удерживает и прогревает**, чем сам генерирует поток заявок.

## 8. Оценка вклада сайта в бизнес

```
Сайт danforge.ru сегодня = визитка + прогрев + SEO-фундамент + портфолио
                         ≠ стабильный автоматический канал заявок
```

**Роль сайта в вашей воронке:**

```
Kwork / рекомендации / inSales каталог  →  danforge.ru (проверка экспертизы)
                                        →  заявка / контакт
                                        →  проект → поддержка
```

Сайт **помогает закрывать сделку**, когда клиент уже заинтересован. Задача на осень — сделать его **генератором** лидов, а не только подтверждением.
