## Блок 2. Проблема → решение

**H2:** Почему штатного поиска мало

| Было | Стало |
|------|-------|
| Dropdown под полем — мало фото, слабая выдача | Полноэкранная панель с сеткой карточек |
| Цены и наличие «как повезёт с темой» | Цена + зачёркнутая старая цена, бейдж «Нет в наличии» |
| Категории и блог — отдельно от поиска | Sidebar категорий + опционально статьи (desktop) / вкладки (mobile) |
| Артикул часто «не ловится» | Поиск по названию и SKU всех вариантов |
| Правка поиска = правка темы при каждом обновлении | Виджет отдельно: настройки в админке, без деплоя темы |
| Пустая выдача без подсказок | Сообщение + ссылка на `/search` + до 5 категорий |

## Блок 4. Возможности

**H2:** Что умеет быстрый поиск

1. **Полноэкранная панель** — тёмный оверлей, открытие по клику на поиск в шапке (CSS-триггеры)
2. **Live-поиск** — выдача после паузы в вводе; поиск по названию и артикулу (SKU)
3. **Карточки как в каталоге** — фото (5 форматов), цена, старая цена
4. **Бейдж «Нет в наличии»** — на фото, если товар недоступен
5. **Категории рядом** — sidebar на desktop, горизонтальная лента на mobile
6. **Статьи блога** — опционально: заголовок, теги, связанные товары; кнопка «Все статьи →»
7. **Честный «Показать ещё»** — подпись «N из M»; ссылка «Все результаты» и Enter → полный `/search`
8. **Аналитика GTM** — события поиска, клика по товару/категории, пустой выдачи

*Не обещать:* снятие лимита 100 статей на блог, серверную бесконечную пагинацию, полнотекстовый поиск по телу статьи.

## Блок 5. Для кого

**H2:** Для кого этот виджет

### Интернет-магазин с каталогом
Большой ассортимент: покупателю важны фото, цена, наличие и быстрый переход. Поиск работает как витрина, а не как строка.

### Content + commerce
Магазины с блогом, обзорами, инструкциями. Один запрос — товар и статья «как выбрать». Пилот: armedf.ru.

### B2B и поиск по артикулу
Клиент знает SKU — находит с первого раза. Нулевые цены («запросите цену») можно скрыть из быстрой выдачи.

## Блок 6. Как подключить

**H2:** Как подключить на inSales

1. **Оставьте заявку** — форма на сайте, Telegram или Kwork. Пришлите URL магазина (gen-2 или gen-4).
2. **Установка** — загружаем виджет, настраиваем триггеры поиска и выдачу (фото, цены, категории; статьи — по пакету).
3. **Проверка на вашем магазине** — desktop и mobile: открытие панели, кириллица, артикул, переход на полный поиск.

**Срок:** обычно 1–3 рабочих дня после доступа в админку (пакет B/C).

## Блок 9. FAQ

**H2:** Частые вопросы

**Чем отличается от штатного AjaxSearch?**  
Полноэкранная панель с сеткой: фото, цена и старая цена, категории, опционально статьи, поиск по SKU, честный «N из M», события для GTM. AjaxSearch — dropdown с урезанной выдачей.

**Можно искать по артикулу (SKU)?**  
Да — по SKU всех вариантов товара, плюс по названию.

**Работает на Gen-2 и Gen-4?**  
Да. Отдельные манифесты для generation 2 и 4.

**Нужно ли править тему?**  
Нет. Виджет подключается отдельно; настройки в админке inSales. Триггеры — CSS-селекторы кнопок/поля поиска.

**Статьи блога?**  
Опционально (`show_articles`). Поиск по заголовку, тегам и связанным товарам. В панели — до 100 статей на блог (лимит Liquid); если больше — кнопка «Все статьи →».  
Пакет C = **включение и настройка** этой функции под ваш блог, **не** написание статей.

**«Показать ещё» подгружает весь каталог?**  
Кнопка раскрывает уже загруженный список порциями («N из M»). Полный каталог по запросу — через «Все результаты» или Enter на страницу `/search`.

**Есть аналитика?**  
Опциональные события в `dataLayer` (GTM): поиск, клик по товару, zero-results, клик по категории.

**Лицензия?**  
Один интернет-магазин — одна лицензия.
