### Блок 2. Проблема → решение — визуал

Две колонки без карточек-«коробочек» лишних границ: слева приглушённый список «штатный AjaxSearch», справа акцент на DanForge.

| Было | Стало |
|------|-------|
| Dropdown под полем, мало фото | Полноэкранная панель + сетка карточек с фото |
| Цены/наличие «как в теме» | Цена + старая цена, бейдж «Нет в наличии» |
| Категории и блог отдельно | Sidebar категорий + статьи (desktop) / tabs (mobile) |
| Нет поиска по SKU «из коробки» | Поиск по названию и артикулу всех вариантов |

### Блок 3. Галерея — визуал и порядок

1. **Desktop split** (главный) — поле поиска, sidebar слева (категории + статьи), сетка товаров справа, подсветка запроса  
2. **Mobile tabs** — sticky «Товары (N)» / «Статьи (N)», rail категорий  
3. **Карточки крупно** — фото, цена, зачёркнутая старая, бейдж «Нет в наличии»  
4. **Zero-results** — «Ничего не найдено…», ссылка на `/search`, подсказки категорий  
5. *(опц.)* Недавние запросы — chips при пустом поле  

Подписи коротко: «Desktop: товары + категории + статьи», «Mobile: вкладки», «Нет в наличии», «Пустая выдача».

### Блок 4. Возможности — 8 пунктов (иконки)

Иконки простые line/outline, один цвет акцента. Без emoji-кластеров.

1. Полноэкранная панель с оверлеем  
2. Live-поиск (debounce), название + SKU  
3. Сетка: фото, цена, старая цена  
4. Бейдж «Нет в наличии»  
5. Категории: sidebar / mobile rail  
6. Статьи блога (опционально)  
7. «Показать ещё» — честный «N из M»  
8. События dataLayer для GTM  

### Блок 5. Для кого — визуал

Три колонки/секции (не «dashboard»):

- **Каталог** — большой ассортимент, фото и наличие  
- **Content + commerce** — товары и статьи в одной панели (как armedf.ru)  
- **B2B / SKU** — поиск по артикулу, фильтр нулевых цен  

### Блок 6. Как работает — 3 шага

1. Заявка (сайт / Telegram / Kwork) + URL магазина  
2. Установка виджета, триггеры поиска, настройки выдачи  
3. Проверка desktop/mobile на вашем магазине  

### Блок 7–11

Как у других модулей: демо-ссылка → таблица цен → FAQ → CTA → другие модули.

**Карточка каталога `/services/modules`:**  
Название «Быстрый поиск» · 1 строка описания · 3–4 галочки фич · «от … ₽» · «Подробнее →».

## 4. Инструкции для Tilda

**URL страницы (рекомендация):** `https://danforge.ru/services/modules/quick-search-widget`  
**Быстрый путь:** дублировать `dynamic-cart-widget` или `reviews-slider-widget` → заменить тексты и картинки.

### 4.1 Cover (Hero)

1. Первый блок **Cover** (как у table-builder / pdf-catalog / dynamic-cart).  
2. **Фон** → загрузить `danforge-quick-search-hero-1920x800.png` (desktop).  
3. Отдельный Cover для mobile или адаптив Tilda → `danforge-quick-search-hero-mobile-1080x1350.png`.  
4. H1 и lead — из §3 (вариант A).  
5. Бейдж партнёра inSales — как на соседних модулях.  
6. Кнопки: «Заказать установку» → `#order` · «Смотреть демо» → `https://armedf.ru` (UTM ниже).  
7. Центр баннера пустой — не дублировать H1 на картинке.

### 4.2 Проблема → решение

1. Блок **2 колонки** (или «Список преимуществ» 2×N).  
2. Заголовок H2: «Вместо dropdown — полноценная панель поиска».  
3. Таблица «Было / Стало» из §1 блок 2.  
4. Без декоративных фиолетовых иконок — outline в цвете бренда.

### 4.3 Галерея скринов

1. Блок **Галерея / слайдер** (как на reviews).  
2. Порядок загрузки:  
   1. desktop split  
   2. mobile tabs  
   3. карточки + OOS (или отдельный слайд)  
   4. zero-results  
3. Подписи — из §3 «подписи к скринам».  
4. Не класть Kwork-обложку 660×440 в галерею продукта (только скрины UI).

### 4.4 Иконки фич

1. Блок **Features / иконки** — 6 или 8 пунктов из §1 блок 4.  
2. Иконки: лупа, сетка, тег цены, folder категорий, документ статьи, chart/GTM.  
3. Заголовок H2: «Что умеет виджет».  
4. В каждой карточке: **жирный заголовок 3–5 слов** + 1 строка пояснения. Не перечислять debounce/AbortController — это не маркетинг.

### 4.5 Для кого + Как работает

1. Три колонки «Для кого» (§1 блок 5).  
2. Три шага «Как заказать» (§1 блок 6).  
3. Демо-блок: кнопка на armedf.ru — «Открыть поиск в шапке и ввести 2+ символа».

### 4.6 Таблица цен

1. Скопировать структуру таблицы с соседнего модуля.  
2. **Не выдумывать цены** — подставить актуальный прайс владельца.  
3. CTA под таблицей: «Напишите URL магазина — проверю совместимость (gen 2 / gen 4) до заказа.»  
4. Лицензия внизу: «Один магазин — одна лицензия.»

### 4.7 FAQ (аккордеон)

Готовые вопросы (ответы по FEATURES, без выдумок):

**Подойдёт ли моей теме?**  
Generation 2 и 4. Напишите URL — скажем до заказа.

**Чем лучше штатного AjaxSearch?**  
Полноэкранная панель, крупные фото, цены и старая цена, категории, опционально статьи, поиск по SKU, честный «N из M», события для GTM.

**Нужно ли править тему?**  
Виджет подключается отдельно. Триггеры — CSS-селекторы кнопок/поля поиска в настройках.

**Статьи блога?**  
Опционально (`show_articles`). Индекс из Liquid; в клиентском индексе до 100 статей на блог. Есть «Все статьи →».  
Пакет C = настройка поиска по вашему блогу, **не** написание статей.

**Есть аналитика?**  
Опциональные события в `dataLayer`: поиск, клик по товару, zero-results, клик по категории.

**Лицензия?**  
Один интернет-магазин — одна лицензия.
