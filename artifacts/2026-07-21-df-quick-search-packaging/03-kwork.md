## Описание (вставить целиком)

### Заголовок внутри описания

**Быстрый поиск для интернет-магазина на inSales — панель вместо dropdown**

### Текст

Штатный AjaxSearch — узкий dropdown: мало фото, слабые цены, нет категорий и статей. Покупатель уходит на страницу поиска и часть запросов «теряется».

Я установлю **виджет быстрого поиска DanForge**: полноэкранная live-панель с сеткой товаров — фото, цена и старая цена, бейдж «Нет в наличии», категории рядом. Поиск по **названию и артикулу (SKU)** всех вариантов. Опционально — **статьи блога** в той же панели.

Виджет **не правит тему**: подключается отдельно, настройки в админке inSales. Совместим с **Gen-2 и Gen-4**. Проверен на боевом магазине.

**Что получаете:**
- Готовый виджет под ваш магазин (один магазин — одна лицензия)
- Настройка триггеров поиска под вашу шапку
- Live-поиск: фото, цены, категории
- Поиск по SKU + опция скрыть товары с нулевой ценой
- Опционально: статьи блога — **поиск по статьям** в панели (пакет «Поиск по статьям»; не написание контента)
- Честный «Показать ещё (N из M)» и переход на полный `/search`
- События для GTM (поиск, клик, zero-results)
- Проверка desktop и mobile

**Кто делает:** Даниил, сертифицированный партнёр inSales, [danforge.ru](https://danforge.ru/services/modules/quick-search-widget).

**Название на Kwork:** `Установка под ключ`

**Состав:**

**Для кого:** типичный e-commerce-каталог. **Рекомендуемый старт.**

### Пакет 3 — Поиск по статьям + донастройка · **12 000 ₽** · срок 3–4 дня

**Название на Kwork:** `Установка + поиск по статьям блога + донастройка`

**Важно:** «статьи» = **настройка поиска по уже существующему блогу** в панели виджета. Написание / редактура постов **не входит**.

**Состав:**
- Всё из «Установка под ключ»
- Включение поиска по статьям (`show_articles`), handles блогов, `articles_blog_url`, ссылка «Все статьи →»
- Подгонка сетки и формата фото под витрину
- При необходимости: поиск под B2B (`hide_zero_price`, акцент на SKU)
- Приёмка: товары + статьи в панели + zero-results + mobile tabs

**Для кого:** магазины с блогом / обзорами (как content+commerce) или B2B с нюансами выдачи.

## FAQ (блок на Kwork)

**Чем лучше штатного AjaxSearch?**  
Полноэкранная панель, крупные фото, цены и старая цена, категории, опционально статьи, поиск по SKU, честный счётчик «N из M», события для GTM.

**Нужно ли править тему?**  
Нет. Виджет отдельно, настройки в админке.

**Gen-2 подойдёт?**  
Да. Есть манифест для Gen-2 и Gen-4.

**Статьи блога?**  
В пакете «Поиск по статьям» включаем и настраиваем поиск по вашему блогу (`show_articles` и т.д.) — **не пишем статьи**. В панели — до 100 статей на блог; если больше — кнопка «Все статьи →».

**«Показать ещё» грузит весь каталог?**  
Раскрывает уже загруженный список. Полный поиск — через «Все результаты» / Enter на `/search`.

**Лицензия?**  
Один магазин — одна лицензия.

**Сроки?**  
Лицензия — в день оплаты. Установка — 2–3 дня. Со статьями — 3–4 дня после доступа в админку.

## Что входит / что не входит

**Входит:** виджет, лицензия на 1 магазин, установка и настройка по выбранному пакету, смоук desktop/mobile.

**Не входит:** редизайн всей шапки/темы; снятие лимита 100 статей платформы; Elastic/сторонний поисковый движок; ежемесячное сопровождение; установка на второй магазин без новой лицензии.
