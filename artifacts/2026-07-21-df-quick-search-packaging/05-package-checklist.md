## 1. Что входит в коммерческую поставку

### 1.1 Файлы виджета (всегда)

Из `projects/df_quick_search/widget/`:

| Файл | Назначение |
|------|------------|
| `info.gen4.json` / `info.gen2.json` → `info.json` | Манифест под поколение темы |
| `snippet.liquid` | Разметка + Liquid-индекс |
| `snippet.js` | Логика поиска / UI |
| `snippet.scss` | Стили |
| `settings_form.json` | Форма настроек админки |
| `settings_data.json` | Defaults |

Опционально в zip клиенту:
- краткая `INSTALL.md` (можно выжимка из README §Установка)
- `FEATURES.md` (коммерческое описание) — по желанию

**Не отдавать клиенту без необходимости:** папку `Пример/`, внутренние UX-артефакты команды, сырые тесты — тесты можно оставить в zip как proof of quality.

### 1.2 Права

- Использование на **одном** домене/магазине inSales
- Минорные багфиксы / обновления — см. варианты в `06-decisions.md` *(модель ещё не утверждена владельцем; рекомендация: бесплатно в рамках major-ветки)*
- Major / новые большие фичи — отдельное решение / доплата

### 1.3 Работы по пакетам

| Пакет | Цена (реком.) | Работы DanForge |
|-------|---------------|-----------------|
| **A. Лицензия** | 5 000 ₽ | Передача zip + инструкция. Без установки. |
| **B. Установка** | 8 000 ₽ | A + загрузка, триггеры, базовая выдача, смоук |
| **C. Поиск по статьям + донастройка** | 12 000 ₽ | B + включение/настройка поиска по статьям блога (`show_articles` и др.), визуальная подгонка, приёмка. **Не** написание статей. |

## 4. Границы (фиксировать в переписке / на сайте)

**Не входит в пакет:**
- Редизайн шапки / темы
- Снятие лимита Liquid 100 статей/блог
- Серверная бесконечная пагинация товаров
- Полнотекстовый поиск по телу статьи (только title, tags, related products)
- Elastic / внешний поисковый движок
- Ежемесячное сопровождение
- Второй магазин без новой лицензии
- Полная настройка GTM-кабинета клиента

**Честные формулировки ограничений:** `01-analysis.md` §7
