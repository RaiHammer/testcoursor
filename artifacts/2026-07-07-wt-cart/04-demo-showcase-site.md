# Концепт: демо-витрина модулей DanForge

**Зачем:** показывать клиентам виджеты и модули «вживую», без установки на их магазин.  
**Статус:** идея — вы планируете создать; корзина — первый экспонат.

---

## Формат

**Рекомендация:** отдельный **inSales-магазин-демо** (не Tilda) — так виджеты работают нативно.

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| **inSales demo-магазин** | Всё работает как у клиента | Нужен тариф / тестовый период |
| Поддомен `demo.danforge.ru` | CNAME на inSales | Настройка DNS |
| Раздел на danforge.ru | Единый бренд | Tilda не запустит inSales-виджет |

**Вывод:** showcase = inSales, с danforge.ru только ссылка «Смотреть демо».

---

## Структура demo-магазина

**Ниша витрины:** fashion (как целевая аудитория корзины) — 8–12 товаров-заглушек (футболки, худи, платья).

**Разделы:**
1. Главная — кратко «Витрина модулей DanForge»
2. Каталог — обычные карточки, кнопка «В корзину» для проверки корзины
3. Страница «Модули» — список что установлено + ссылка на заказ на danforge.ru

**Первый модуль на витрине:**
- `danforge_dynamic_cart` — Динамичная корзина

**Позже:**
- другие виджеты по мере упаковки
- кастомные блоки, фильтры и т.д.

---

## Минимальный чеклист запуска demo

1. [ ] Создать inSales-магазин (тестовый / партнёрский тариф)
2. [ ] Тема generation 4 (бесплатная или минимальная)
3. [ ] 8–12 demo-товаров с фото (можно stock / placeholder)
4. [ ] Установить `danforge_dynamic_cart`
5. [ ] Иконка корзины в шапке → `openCartModal()`
6. [ ] Баннер на главной: «Это демо-магазин DanForge. Заказать модуль → danforge.ru/dynamic-cart»
7. [ ] Записать 15–30 сек screen recording (desktop + mobile) для Kwork и danforge
8. [ ] DNS: `demo.danforge.ru` → магазин inSales

## Связка с продажами

| Канал | Как используем demo |
|-------|---------------------|
| **Kwork** | Галерея + «Живое демо: demo.danforge.ru» |
| **danforge.ru** | Кнопка «Смотреть вживую» на странице продукта |
| **Переписка с клиентом** | Одна ссылка вместо скринов |
| **Портфолио** | «Модули» как отдельный тип кейса |

## Оценка времени

| Задача | Время |
|--------|-------|
| Магазин + тема + товары | 3–5 ч |
| Установка корзины + шапка | 1 ч |
| Скрины + видео | 1–2 ч |
| DNS + ссылка с сайта | 30 мин |

**Итого:** один рабочий день на MVP витрины с одним виджетом.
