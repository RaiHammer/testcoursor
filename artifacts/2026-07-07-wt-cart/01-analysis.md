# Анализ продукта: Динамичная корзина (wt_cart)

**Task ID:** 2026-07-07-wt-cart  
**Дата:** 2026-07-07  
**Источник:** `projects/wt_cart/` (из wt_cart.zip)

## Суть продукта

Side-panel / bottom-sheet **динамическая корзина** для inSales:
- Открывается при добавлении товара (`EventBus add_items`)
- Обновляется без перезагрузки (`update_items`, `always`)
- Desktop: выезжает справа (385px)
- Mobile: bottom sheet с горизонтальным скроллом товаров
- Размеры/опции товара, +/- количество, удаление
- Промокод, итого, оформление заказа
- Два заголовка: обычный и «товар добавлен»

## Целевая аудитория

- **Fashion / одежда** — основной запрос клиентов Даниила
- Любые inSales-магазины с акцентом на UX корзины
- Магазины, где стандартная корзина платформы не устраивает

## Сильные стороны

- Уже **обкатан** на реальных проектах (мода)
- Корректная работа с **EventBus inSales** и `Cart.forceUpdate`
- Защита от пустого списка при верной сумме (`getOrderLinesFromData`)
- **Mobile-first**: отдельная UX-модель (bottom sheet + horizontal scroll)
- `window.openCartModal` — можно вызывать с иконки корзины в шапке
- BNPL modal include — совместимость с рассрочкой
