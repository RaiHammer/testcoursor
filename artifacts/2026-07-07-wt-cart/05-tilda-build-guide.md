## Шаг 1. Создать страницу

1. Tilda → **Страницы** → **Добавить страницу**
2. **Проще всего:** открыть `table-builder-widget` → **⋯ → Дублировать** → переименовать
3. **Настройки страницы:**
   - Название: `Динамичная корзина`
   - URL: `services/modules/dynamic-cart-widget`
   - Папка: как у других страниц `/services/modules/`

## Шаг 5. Таблица «Что умеет виджет»

Скопируйте блок таблицы с `table-builder-widget`. Замените строки:

| Функция | Описание |
|---------|----------|
| **Автооткрытие** | Корзина появляется сразу после «В корзину», с отдельным заголовком «Товар добавлен» |
| **Без перезагрузки** | Изменение количества, удаление, промокод — через EventBus и Cart API inSales |
| **Desktop** | Боковая панель справа (385px), затемнение фона, закрытие по overlay |
| **Mobile** | Bottom sheet снизу, товары в горизонтальном скролле |
| **Варианты товара** | Размер, цвет и другие опции в строке заказа |
| **Промокод** | Ввод и применение купона без ухода со страницы |
| **Иконка в шапке** | Открытие корзины по клику через `window.openCartModal()` |
| **Оформление заказа** | Переход в стандартный checkout inSales — платформа не меняется |

## Шаг 9. FAQ (аккордеон, если есть на шаблоне)

**Подойдёт ли моей теме?**  
Нужна тема inSales generation 4 с EventBus. Напишите URL магазина — скажу до заказа.

**Можно убрать подпись DanForge внизу корзины?**  
Да, блок копирайта редактируется в настройках виджета.

**Это замена checkout inSales?**  
Нет. Оформление заказа идёт через стандартную корзину платформы.

**Сроки?**  
1–2 рабочих дня после доступа в админку.

**Лицензия?**  
Один интернет-магазин — одна установка.
