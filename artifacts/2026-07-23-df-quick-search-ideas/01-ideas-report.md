# Возможности: DanForge Quick Search (v1.0.9)

**Дата:** 2026-07-23  
**Роль:** Analyst  
**Продукт:** `danforge_quick_search` · gen-4 widget + gen-2 theme-snippet  
**Пилоты:** armedf.ru (gen-4), sushivenik.ru (gen-2)  
**Тип:** идеи / opportunity — без реализации  
**Источники:** README, FEATURES, CHANGELOG, `settings_form.json`, `snippet.js`, packaging `artifacts/2026-07-21-df-quick-search-packaging/`

Canvas (интерактивный): `canvases/df-quick-search-ideas.canvas.tsx` в workspace Cursor.

---

## 1. Executive summary (топ-возможности)

1. **«В корзину» с карточки** — сейчас карточка только `<a href>` на товар; быстрый add-to-cart даёт измеримый рост конверсии и сильный демо-аргумент на продажах.
2. **Фильтр выдачи по клику на категорию** — клик ведёт наружу; in-panel filter удерживает пользователя в поиске (desktop sidebar уже готов под это).
3. **Вернуть layout-suggest UI** — retry RU↔EN уже работает; empty-state «Возможно, вы имели в виду…?» отключён с v0.0.36 — дешёвый UX-win.
4. **Тема магазина (accent / radius)** — 21 настройка, но нет цветовой подгонки; «вписывается в шапку» снижает трение установки и возражения на Kwork.
5. **Снизить вес статей в HTML** — content+commerce (пакет C 12k₽) упирается в JSON-индекс на каждой странице; это и риск поддержки, и ограничитель upsell.
6. **DX синхронизации Gen-2 ↔ Gen-4** — июльский CHANGELOG: syntax drift, critical CSS, chrome без asset; каждый пилот = риск и часы поддержки.
7. **Группы настроек + пресеты** — плоский список из 21 пункта усложняет установку B/C; пресеты «B2B / витрина / блог» ускоряют пакеты.
8. **Популярные из аналитики** — CSV вручную; события `df_qs_*` уже есть — авто-чипы усиливают empty-state без работы админа.

## 2. Новые фичи (интересное + доход)

| Идея | Зачем | Уже есть (база) |
|------|-------|-----------------|
| **Quick add to cart** на карточке (опц. настройка) | Конверсия + демо vs AjaxSearch | Карточка: фото, цена, stock badge; enrich с variants |
| **Фильтр по категории в панели** (chip toggle) | Удержание в поиске; меньше уходов на коллекцию | Sidebar/rail категорий; `buildCategoryMap` |
| **Показ артикула / бренда на карточке** | B2B-оффер (SKU уже ищется, но не виден) | Поиск по SKU всех variants |
| **Выбор варианта** (размер/цвет) перед add-to-cart | Нужен для магазинов с options | `variants` после enrich |
| **Синонимы / словарь запросов** (админка CSV) | Качество выдачи без API морфологии | Popular CSV; layout-fix RU↔EN |
| **Горячая клавиша** `/` или `Ctrl/⌘+K` | Power-user + «современный» UX в демо | Триггеры CSS + focus trap |
| **Связанные товары при zero-results** | Спасает пустую выдачу | Категории-подсказки; zero-results → `/search` |
| **Поиск по свойствам** (частично, если API отдаёт) | Дифференциация для каталогов с характеристиками | Гибрид suggestions + search.json |
| **Авто-popular из dataLayer / session** | Empty-state без ручного CSV | `df_qs_search`, popular chips |
| **«Недавние» в localStorage** (опц.) | Между вкладками/визитами | Recent в sessionStorage, только hits |

**Факт:** коммерческая упаковка готова (5/8/12k₽), публикация Tilda/Kwork ещё вручную — продуктовые фичи выше усиливают скрины и оффер, но **не заменяют** публикацию.

## 4. Performance / технические оптимизации

| Идея | Зачем | Ограничение сейчас |
|------|-------|---------------------|
| Вынести индекс статей в **отдельный JSON-asset / lazy fetch** | Меньше HTML на каждый page view | Liquid-индекс в HTML; localStorage 24ч только на parse |
| Cache key статей по **hash title/updated**, не только `articles.size` | Актуальные заголовки без «залипания» | Документировано в README |
| **Prefetch** enrich для top-N suggestions | Быстрее первая отрисовка карточек | Chunk products_by_id по 40 |
| Параллель suggestions ∥ частичный search.json | Ниже latency на cold | Последовательная цепочка |
| IndexedDB для большого индекса статей | Обход лимита localStorage | 500+ статей (armedf) |
| Сократить критический CSS / разделить gen-2 chrome | Меньше дублирования liquid↔asset | v1.0.7–1.0.9 critical chrome |
| Service Worker / HTTP cache для search.json — **не рекомендуется** без политики | Сложность + stale | In-memory 60s достаточно для v1 |

## 6. Gen-2 vs Gen-4: паритет и надёжность

**Факт из CHANGELOG (2026-07-23):** серия релизов v1.0.5–1.0.9 почти целиком про паритет и заливку Gen-2 (syntax, critical overlay/panel, chrome без CSS-asset).

| Идея | Тип |
|------|-----|
| Единый **release checklist** gen-2/gen-4 с обязательным Network 200 на CSS | Процесс |
| Автотест: critical selectors присутствуют в liquid **и** в compiled CSS | Техдолг |
| Версия в UI (data-атрибут / comment) для диагностики пилотов | Support |
| Smoke-скрипт против armedf + sushivenik (ручной чеклист → полуавтомат) | QA |
| Не раздувать SimpleWidget gen-2 как primary — theme-snippet остаётся каналом | Стратегия (уже верно в README) |

## 8. Не рекомендуется сейчас (scope traps)

| Идея | Почему отложить |
|------|-----------------|
| Полнотекстовый поиск по телу статьи | Нет публичного API; раздувает индекс; в packaging явно «не входит» |
| Собственный поисковый бэкенд / Algolia / Meilisearch | Инфра, SaaS, ломает модель «разовый виджет» |
| Подмена штатного AjaxSearch dropdown | Конфликты тем; продукт сознательно — своя панель |
| Голосовой поиск | Нишево, поддержка браузеров, мало ROI для inSales-ниши |
| Wishlist / сравнение из панели | Другой продукт; размывает фокус Quick Search |
| Service Worker кэш каталога | Stale + сложная инвалидация |
| Морфология русского «как у Яндекса» | Без своего индекса — иллюзия; лучше синонимы вручную |
| Marketplace inSales как канал до публикации danforge/Kwork | Сначала закрыть упаковку и пилотные скрины |
| Бесконечное расширение settings без групп | UX админки деградирует быстрее, чем ценность |
