## Полное описание (вставить целиком)

### Заголовок внутри описания

**Быстрый поиск для интернет-магазина на inSales — панель вместо dropdown (v1.0.9)**

### Текст

Штатный AjaxSearch — узкий dropdown: мало фото, слабые цены, нет категорий и статей. Покупатель уходит на страницу поиска, а часть запросов «теряется» из‑за раскладки или артикула.

Я установлю **виджет быстрого поиска DanForge v1.0.9**: полноэкранная live-панель **Layout B** — на desktop товары + sidebar, на mobile вкладки «Товары / Статьи». Сетка с фото, ценой и старой ценой, бейдж «Нет в наличии». Поиск по **названию и артикулу (SKU)** всех вариантов. Исправление раскладки **RU↔EN**, сортировка в панели, чипы популярных и недавних запросов. При необходимости — **полный индекс статей блога** в той же панели (настройка поиска по вашему блогу, не написание постов).

Подключение **без правки темы**: Gen-4 — SimpleWidget; Gen-2 — **theme-snippet** (liquid + CSS). **21 настройка** в админке inSales. Проверен на боевом магазине ([armedf.ru](https://armedf.ru)) и на теме Gen-2.

**Базовая услуга (14 000 ₽) — установка под ключ:**
- Готовый виджет под ваш магазин (один магазин — одна лицензия), v1.0.9

- Настройка триггеров поиска под вашу шапку
- Live-поиск Layout B: фото, цены, категории
- Поиск по SKU + опция скрыть товары с нулевой ценой
- Сортировка, popular / recent, RU↔EN
- Настройка статей блога в панели (если блог уже есть)
- Честный «Показать ещё (N из M)» и переход на `/search`

## FAQ (блок на Kwork)

**Чем лучше штатного AjaxSearch?**  
Полноэкранная панель Layout B, крупные фото, цены и старая цена, категории, опционально статьи, поиск по SKU, сортировка, RU↔EN, честный счётчик «N из M», события для GTM.

**Нужно ли править тему?**  
Нет. Gen-4 — виджет отдельно; Gen-2 — theme-snippet. Настройки в админке (21 параметр). Триггеры — CSS-селекторы.

**Gen-2 подойдёт?**  
Да. Primary поставка Gen-2 — **theme-snippet** (liquid + CSS вместе). Есть и запасной SimpleWidget Gen-2.

**Статьи блога?**  
В базовой установке включаем и настраиваем поиск по вашему блогу — **не пишем статьи**. Индекс полный (Liquid). Поиск по заголовку, тегам, связанным товарам. При большом блоге индекс даёт вес HTML. «Все статьи →» — на страницу блога.

**Что с раскладкой клавиатуры?**  
Авто-retry RU↔EN при пустой выдаче + баннер успеха — всегда включено.

**«Показать ещё» грузит весь каталог?**  
Раскрывает уже загруженный список. Полный поиск — через «Все результаты» / Enter на `/search`.

**Лицензия?**  
Один магазин — одна лицензия. Обновления — по политике DanForge. Только файлы без установки — 5 000 ₽ (напишите до заказа).

**Сроки?**  
Базовая установка — 2–3 дня после доступа в админку. Со срочной опцией — 1 рабочий день (если слот свободен).

**Почему нет пакетов «Эконом / Стандарт / Премиум»?**  
В категории «Доработки сайта» на Kwork доступны только базовая услуга и опции. Состав тот же, что на сайте: установка 14 000, донастройка дизайна — опцией.
