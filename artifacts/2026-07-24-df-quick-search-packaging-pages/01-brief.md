## 3. Аудитории / messaging pillars

Сегменты без смены стратегии; формулировки — под v1.0.9.

### 3.1 E-commerce (каталог)

- **Боль:** dropdown без витрины; уход на `/search`; поиск «вшит» в тему.
- **Message:** полноэкранная сетка — фото, цена, скидка, наличие; сортировка в панели; popular/recent.

### 3.2 Content + commerce

- **Боль:** статьи и товары в разных местах; большой блог.
- **Message:** один запрос — товар и статья; **полный индекс** блога(ов) в панели + «Все статьи →»; в turnkey 14k — **настройка** поиска по блогу, не контент.
- **Пилот в оффере:** armedf.ru (разрешён).

### 3.3 B2B / SKU

- **Боль:** артикул «не находится»; нулевые цены засоряют выдачу.
- **Message:** SKU всех вариантов + `hide_zero_price`; Layout fix RU↔EN для опечаток раскладки.

### Pillars (обновить словарь SEO/Designer)

1. **«Поиск как витрина, не как строка.»** — Layout B, фото, цены в ряд, stock badge.
2. **«Товар и статья в одном запросе.»** — полный индекс блога при `show_articles` (не «100 статей»).
3. **«Артикул с первого раза.»** — SKU + опционально скрыть цену 0.
4. **«Без правки темы.»** — виджет / theme-snippet; 21 настройка; триггеры CSS.
5. **«Честная выдача.»** — строгий фильтр; «N из M»; RU↔EN retry; без обещаний Elastic/полнотекста тела статьи.

**Убрать из публичных текстов:** «до 100 статей на блог» / «снятие лимита 100» как главный caveat.  
**Заменить на:** полный индекс указанных блогов; при большом блоге — вес страницы + кнопка «Все статьи →»; поиск по title / tags / related products.
