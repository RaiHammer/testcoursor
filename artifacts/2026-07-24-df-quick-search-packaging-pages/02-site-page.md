## Блок 2. Проблема → решение

**H2:** Почему штатного поиска мало

| Было | Стало |
|------|-------|
| Dropdown под полем — мало фото, слабая выдача | Полноэкранная панель Layout B: сетка карточек + sidebar / вкладки |
| Цены и наличие «как повезёт с темой» | Цена + зачёркнутая старая цена, бейдж «Нет в наличии»; цены в ряд |
| Категории и блог — отдельно от поиска | Категории рядом; статьи — полный индекс указанных блогов (опционально) |
| Артикул часто «не ловится» | Поиск по названию и SKU всех вариантов |
| Опечатка раскладки (RU вместо EN) — пустая выдача | Авто-retry RU↔EN + баннер успеха |
| Правка поиска = правка темы при каждом обновлении | Gen-4 виджет или Gen-2 theme-snippet: настройки в админке |
| Пустая выдача без подсказок | Ссылка на `/search` + до 5 категорий; чипы popular / recent |

## Блок 4. Возможности

**H2:** Что умеет быстрый поиск

1. **Полноэкранная панель Layout B** — desktop: sidebar (~категории + статьи) + сетка товаров; mobile: sticky-вкладки «Товары» \| «Статьи»
2. **Live-поиск** — выдача после паузы в вводе; поиск по названию и артикулу (SKU всех вариантов)
3. **Карточки как в каталоге** — фото (5 форматов), цена и старая цена, выровненные по низу ряда
4. **Бейдж «Нет в наличии»** — на фото, если товар недоступен; опция скрыть нулевые цены
5. **Сортировка в панели** — по умолчанию / цена ↑↓ / популярность (по загруженному списку)
6. **Статьи блога** — опционально: полный Liquid-индекс указанных блогов; поиск по заголовку, тегам, связанным товарам; кнопка «Все статьи →»
7. **Умная выдача** — исправление раскладки RU↔EN; чипы popular (до 12) и recent (до 5 при hits); честный «N из M» и переход на `/search`
8. **21 настройка + GTM** — фото, цены, категории, статьи, сортировка и др. в админке; события dataLayer

*Не обещать:* ATC в панели, Algolia/Elastic, полнотекст тела статьи, «лёгкий HTML» при очень большом блоге.

## Блок 5. Для кого

**H2:** Для кого этот виджет

### Интернет-магазин с каталогом
Большой ассортимент: покупателю важны фото, цена, наличие и быстрый переход. Поиск работает как витрина — с сортировкой и чипами популярных запросов.

### Content + commerce
Магазины с блогом, обзорами, инструкциями. Один запрос — товар и статья. Полный индекс блога(ов) в панели + «Все статьи →». Пилот: [armedf.ru](https://armedf.ru).

### B2B и поиск по артикулу
Клиент знает SKU — находит с первого раза. Нулевые цены («запросите цену») можно скрыть. Опечатки раскладки RU↔EN не обрывают поиск.

## Блок 9. FAQ

**H2:** Частые вопросы

**Чем отличается от штатного AjaxSearch?**  
Полноэкранная панель Layout B: фото, цена и старая цена, категории, опционально статьи, поиск по SKU, сортировка, RU↔EN, честный «N из M», события для GTM. AjaxSearch — dropdown с урезанной выдачей.

**Можно искать по артикулу (SKU)?**  
Да — по SKU всех вариантов товара, плюс по названию. Нулевые цены можно скрыть из быстрой выдачи.

**Работает на Gen-2 и Gen-4?**  
Да. Gen-4 — SimpleWidget. Gen-2 — primary **theme-snippet** (liquid + CSS вместе); SimpleWidget Gen-2 — запасной вариант.

**Нужно ли править тему?**  
Нет. Виджет / сниппет подключается отдельно; **21 настройка** в админке inSales. Триггеры — CSS-селекторы кнопок и поля поиска.

**Как устроен поиск по статьям блога?**  
Опционально (`show_articles`). Строится **полный Liquid-индекс** указанных блогов (по `articles.size`). Поиск по заголовку, тегам и связанным товарам — не по полному тексту тела статьи. При большом блоге индекс добавляет вес HTML на страницу; кэш Liquid ключуется по размеру индекса и locale (правка только title без смены числа статей может кешироваться). Кнопка «Все статьи →» ведёт на страницу блога / после локальных совпадений.  
Пакет C = **включение и настройка** этой функции под ваш блог, **не** написание статей.

**Что с опечатками раскладки (набрал по-русски английское слово)?**  
Включено всегда: при пустой выдаче виджет пробует другую раскладку RU↔EN и показывает баннер успеха.

**«Показать ещё» подгружает весь каталог?**  
Кнопка раскрывает уже загруженный список порциями («N из M»). Полный каталог по запросу — через «Все результаты» или Enter на страницу `/search`. Сортировка тоже работает по уже загруженному буферу.

**Лицензия и обновления?**  
Один интернет-магазин — одна лицензия. Обновления — по политике DanForge.
