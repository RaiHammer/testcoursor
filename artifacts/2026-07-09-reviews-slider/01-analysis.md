# Анализ продукта: Слайдер отзывов (inSales + Яндекс)

**Статус:** упаковка завершена (2026-07-09)  
**Референс UI:** скрин слайдера «Отзывы покупателей» (аватар, звёзды, пагинация)

---

## Суть продукта

**Объединённый слайдер отзывов** на главной inSales-магазина:
- отзывы о **товарах** из магазина
- отзывы о **компании** из Яндекс Карт
- один красивый слайдер вместо ручного добавления слайдов в блоках Tilda/конструкторе

**Техническая модель (как у InSales Studio):**
1. Утилита (CLI) собирает отзывы → кэш
2. Генерирует Liquid-сниппет со слайдами
3. Загружает в тему магазина (опционально флаг `-u`)
4. Виджет-слайдер на главной подключает этот сниппет

---

## Зачем это клиенту

| Боль | Решение |
|------|---------|
| Отзывы разрознены: товары в inSales, компания в Яндексе | Один блок на главной |
| В конструкторе каждый отзыв — ручной слайд | Автогенерация из актуальных данных |
| 600+ отзывов — тяжёлая страница | Случайный срез N штук |
| Аватары Яндекса — внешние URL | Загрузка в «Файлы» магазина |

**Целевая аудитория:** любой inSales с активными отзывами (не только fashion). Особенно магазины с сильным Яндекс-профилем.

## Конкурент / референс

**InSales Studio** ([пост](https://vk.com/wall-168159378_28)):
- PHP-утилита `get-reviews`
- Кэш + Liquid + загрузка сниппета
- **Минус для клиента:** «добавить сниппет в код слайдера придётся самостоятельно»
- Продают генерацию сниппетов под заказ

**УТП DanForge:**
- Готовый **виджет-слайдер** (не DIY)
- Установка под ключ
- Брендинг DanForge, страница на danforge.ru + Kwork
- Документация и поддержка

**Встроенный inSales RS-6:** выводит отзывы по товарам, но **без Яндекса** и без объединения — не прямой конкурент полного решения.

## Техническая реализуемость

### 1. Отзывы inSales ✅

Admin API:
```
GET /admin/reviews.json
```
Поля: author, content, rating, created_at, published, product_id, url, images.

Пагинация — стандартная для inSales API. Фильтр: только `published: true`.

### 2. Отзывы Яндекс ⚠️

**Публичного API нет** (официально — только виджет Яндекса на сайт).

Варианты:
| Подход | Плюсы | Минусы |
|--------|-------|--------|
| Парсинг страницы org Яндекс Карт | Как у Studio, полный контроль | Хрупко при смене вёрстки, нужен headless/cron |
| Python `yandex-reviews-parser` | Готовые библиотеки | Зависимость, тоже парсинг |
| Apify / платный scraper | Стабильнее | Стоимость на клиента |
| Только виджет Яндекса iframe | Легально | Не в едином слайдере — другой UX |

**Рекомендация:** парсинг org URL (как Studio), с версионированием парсера и запасным ручным JSON-импортом.

### 3. Генерация Liquid + загрузка ✅

- Шаблон слайда: author, rating stars, text, avatar, source badge (inSales / Яндекс)
- Сниппет: `danforge_reviews_slides.liquid`
- Загрузка через Theme API / админку (флаг `-u` в CLI)
- Кэш: JSON locally + generated liquid

### 4. Виджет-слайдер ✅

Gen-4 widget:
- Swiper / аналог (как на скрине — точки, один отзыв по центру)
- `{% include 'danforge_reviews_slides' %}` или чтение JSON из Files
- Настройки: заголовок, ссылка «Оставить отзыв», кол-во слайдов, autoplay
- Handle: `danforge_reviews_slider`

### 5. Аватары Яндекс ✅

Скачать `author_icon_url` → upload в Files inSales → подставить URL в liquid.

## Риски

1. **Яндекс-парсер сломается** — заложить мониторинг + быстрый фикс; fallback: только inSales-отзывы
2. **Cron** — клиенту нужен cron (хостинг/VPS) или услуга «обновление раз в месяц» от DanForge
3. **API-ключ inSales** — нужен доступ приложения с правами на reviews + themes
4. **Юридическое** — парсинг Яндекса в серой зоне; не рекламировать как «официальная интеграция с Яндексом»
5. **Рейтинг inSales** — в API rating 1–10, в UI звёзды 1–5 — нормализация
