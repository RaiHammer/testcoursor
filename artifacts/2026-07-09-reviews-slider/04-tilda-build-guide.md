## Блок «О модуле»

**H2:** Все отзывы в одном месте

Виджет заменяет ручное добавление слайдов в конструкторе. Утилита DanForge собирает отзывы, формирует слайды и загружает в тему. Покупатель видит живые отзывы с аватаром и звёздами.

**Идеально для:**
- Магазинов с активными отзывами о товарах
- Компаний с рейтингом в Яндекс Картах
- Главной страницы — социальное доказательство

## Таблица «Что умеет»

| Функция | Описание |
|---------|----------|
| **inSales** | Выгрузка опубликованных отзывов о товарах через Admin API |
| **Яндекс** | Отзывы о компании с карточки организации |
| **Слайдер** | Swiper: аватар, имя, звёзды, текст, источник |
| **Срез** | При 100+ отзывах — случайная выборка N штук |
| **Обновление** | Перезапуск утилиты — 5 минут, сервер не нужен |
| **CTA** | Ссылка «Оставить отзыв» внизу слайдера |
