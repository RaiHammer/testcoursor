# Чеклист пилота: Слайдер отзывов

Перед установкой на клиентском магазине.

---

## Что попросить у клиента

- [ ] URL магазина (myinsales.ru)
- [ ] Доступ в админку **или** временный доступ для установки
- [ ] **API-ключ:** Настройки → Приложения → Разработчикам → создать ключ  
  - Права: чтение отзывов, темы (для `-u`)
- [ ] Ссылка на организацию в **Яндекс Картах** (с отзывами)
- [ ] Сколько отзывов показывать (default: 20)
- [ ] Куда ведёт «Оставить отзыв» (страница товара / /reviews / форма)

---

## Установка (вы)

- [ ] Создать виджет из `projects/df_reviews_slider/widget/`
- [ ] Добавить на главную
- [ ] `config.json` → `python get_reviews.py -u`
- [ ] Если Яндекс не распарсился → JSON fallback или только inSales
- [ ] Desktop + mobile проверка
- [ ] Скриншоты для Kwork/danforge

---

## После пилота

- [ ] Отзыв клиента (можно на Kwork)
- [ ] Зафиксировать: сработал ли парсер Яндекса
- [ ] Цена финальная (8–12k?)
- [ ] Упаковка Kwork + danforge

---

## Типовые проблемы

| Проблема | Решение |
|----------|---------|
| Swiper не работает | Подключить swiper на теме или в libraries |
| Include not found | Запустить CLI с `-u` или вставить snippet вручную |
| Яндекс 0 отзывов | `yandex_reviews_file` или только inSales |
| API 401 | Проверить ключ и пароль |
| Upload snippet fail | Вставить `output/danforge_reviews_slides.liquid` в редактор темы |
