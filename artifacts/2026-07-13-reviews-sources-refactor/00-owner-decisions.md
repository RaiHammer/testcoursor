# Решения владельца — dual-source refactor

**Дата:** 2026-07-13

## 1. Страницы установки

Виджет должен работать **на любых страницах**: главная, отдельная страница отзывов, каталог, прочие.

**Следствие для реализации:**
- Не полагаться только на `paginate` / `blog.url` текущей страницы.
- Spike: проверить prefetch на разных контекстах; AJAX load-more — с fallback (больший prefetch или URL страницы отзывов из настройки).
- Первичная загрузка inSales — всегда через `{% prefetch account.reviews_not_spam %}` в Liquid (работает везде).

## 2. Вкладки и блоки

- Вкладка **«Все» не нужна** (пока).
- Два источника — **два отдельных блока**: InSales и Яндекс.
- При `source-tabs: true` — вкладки **InSales | Яндекс** (без «Все»); активная вкладка показывает один источник.
- При `source-tabs: false` — оба блока видны (InSales сверху или по порядку в разметке), без merge в один список.

**Не делать:** `mergeAllSourcesByDate`, вкладку `data-source-tab="all"`.

## 3. Phase 1 hotfix

Владелец делегирует решение Jarvis.

**Решение:** Phase 1 **пропускаем**. Sort fix (`random.shuffle` → date DESC) и починка вкладок входят в Phase 2 — иначе двойная работа и откат hotfix при смене архитектуры.
