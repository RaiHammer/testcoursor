# CLI update: дополнительные источники Яндекса

**Дата:** 2026-07-20  
**Статус:** выполнено (этап 2 — Яндекс Магазин digest)

## Что сделано

1. Этап 1: JSON-LD fallback + URL normalization для shop.
2. **Этап 2:** пагинация Яндекс Магазина через `/ugcpub/digest`:
   - определение `reviews.yandex.ru/shop/...`
   - извлечение `objectId` (`/site/base64domain`)
   - fetch offset/limit до `pager.reviewCount`
   - парсинг `view.views` где `type == /ugc/review`
3. Тест «Тест Яндекса» для shop показывает:
   - счётчик на витрине (например 87)
   - сколько реально доступно с текстом через API (например 31)
4. Unit-тесты на shop helpers.
