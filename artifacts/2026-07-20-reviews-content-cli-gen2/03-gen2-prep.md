# Подготовка gen-2 версии: стартовый план

**Дата:** 2026-07-20  
**Статус:** analysis done — см. `04-gen2-nivona-analysis.md`; scaffold v0.1 в `projects/df_reviews_slider_gen2/`  
**Пилот:** **nivona.ru** — reference `projects/df_reviews_slider/nivona.ru/`

## Цель

Подготовить отдельную ветку виджета для клиентов на шаблонах inSales поколения 2 (без поломки текущей gen-4 версии).

## Почему отдельная версия

- В текущем продукте `df_reviews_slider` используется `generation: 4`.
- gen-2 и gen-4 отличаются по окружению и поведению editor/settings.
- Совмещение в одном пакете увеличит риск регрессий для текущих клиентов.

## Минимальный scope v0

1. Yandex-only режим (без inSales product-reviews интеграции).
2. 1-2 макета (slider + list/grid), без сложных режимов.
3. Базовые настройки: лимит, min_rating, цвета/типографика.
4. Ручная установка через сниппет с простой инструкцией.

## Технические шаги

1. Снять reference-виджет gen-2 (скелет `info/settings/snippet`).
2. Создать `projects/df_reviews_slider_gen2/` (или отдельную ветку в текущем проекте). ✅ scaffold 20.07
3. Перенести безопасное ядро из текущего JS/Liquid без gen-4-специфики.
4. Добавить smoke-проверку на **nivona.ru** (пилот). ✅ анализ темы 20.07 → `04-gen2-nivona-analysis.md`
5. Подготовить чеклист установки для клиентов. ✅ install steps в `04-gen2-nivona-analysis.md` §5

## Риски

- Различия в рендере и настройках между магазинами gen-2.
- Дополнительная поддержка двух продуктовых веток.
- Рост времени на тестирование и выпуск обновлений.
