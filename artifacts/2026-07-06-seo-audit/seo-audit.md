## 5 рекомендаций (приоритет)

### 1. Запустить контент-блог (высокий)

**Проблема:** Секция статей пуста или не индексируется.  
**Действие:** Опубликовать 3–5 статей: «Миграция с WooCommerce», «InSales vs Tilda для магазина», «Как выбрать разработчика inSales».  
**Tilda:** Добавить блок Zero или T123 с карточками статей, ссылки на отдельные страницы.  
**Сложность:** средняя

### 2. Schema.org разметка (высокий)

**Проблема:** Нет явной structured data для Organization, FAQ, Reviews.  
**Действие:** В Tilda → SEO → добавить JSON-LD: Organization, FAQPage (из блока FAQ), AggregateRating (отзывы).  
**Сложность:** низкая–средняя

### 3. Уникальные meta description для страниц услуг (средний)

**Проблема:** Страницы услуг могут иметь шаблонные description.  
**Действие:** Для каждой услуги — уникальный description 150–160 символов с CTA и ключевым словом.  
**Сложность:** низкая

### 4. Убрать дубли hero-текста (средний)

**Проблема:** «Профессиональная разработка...» повторяется дважды на главной.  
**Действие:** Оставить один H1, второй блок — другой текст (benefits, цифры).  
**Сложность:** низкая

### 5. Внутренняя перелинковка кейсов (средний)

**Проблема:** Кейсы в портфолио без явных ссылок на страницы услуг.  
**Действие:** Под каждым кейсом — ссылка «Заказать такую же доработку» → страница услуги.  
**Сложность:** низкая
