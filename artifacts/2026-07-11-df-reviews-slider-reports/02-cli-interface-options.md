# Отчёт: варианты оболочки (GUI) программы get-reviews

**Дата:** 2026-07-11  
**Автор:** Architect + Analyst (DanForge)  
**Проект:** `df_reviews_slider/cli`  
**Текущая оболочка:** Tkinter + `ttk` (`gui.py`, ~480 строк)

---

## Что не нравится в текущем UI (типичные боли Tkinter)

- Визуально «Windows 95 / утилита разработчика», не «продукт DanForge».
- Плотная форма без группировки, много полей в одном экране.
- Нет тёмной темы, брендинга, иконок.
- Журнал внизу — ок, но нет фильтра/поиска по логам.
- Нет прогресс-бара при долгом парсинге Яндекса.
- Сложно масштабировать: мастер, дашборд, история запусков — всё в одном окне.

**Что работает хорошо (сохранить):**
- мульти-клиент слева;
- кнопки «Проверить API», «Тест Яндекса», dry-run;
- не нужен браузер для работы;
- один `python gui.py` / `start.bat`.

---

## Варианты оболочки

### 1. Tkinter + CustomTkinter / ttkbootstrap (эволюция)

**Суть:** оставить Python desktop, заменить виджеты на современные темы.

| | |
|--|--|
| **Плюсы** | Минимальная миграция; тот же код `get_reviews.py`; exe через PyInstaller как сейчас; 1–2 дня на «косметику». |
| **Минусы** | Потолок дизайна; всё ещё не web-look. |
| **Стек** | `customtkinter` или `ttkbootstrap` |
| **Оценка** | 8–16 ч (редизайн) / 24–40 ч (редизайн + UX) |

**Когда выбирать:** нужен быстрый win без смены стека.

---

### 2. PySide6 / PyQt6 (Qt)

**Суть:** нативное desktop-приложение с Qt Designer.

| | |
|--|--|
| **Плюсы** | Профессиональный UI, трей, уведомления, системные диалоги; хорошие таблицы/деревья для клиентов. |
| **Минусы** | Тяжелее зависимости; лицензия Qt (PySide6 — LGPL, ок); больше кода UI. |
| **Оценка** | 40–80 ч полная переписка GUI |

**Когда выбирать:** долгосрочный desktop-продукт для Windows/macOS.

---

### 3. Electron / Tauri + локальный API

**Суть:** фронт React/Vue/Svelte, бэкенд — Python FastAPI или вызов CLI.

```
[React UI] <--HTTP--> [FastAPI / subprocess get_reviews.py]
```

| | |
|--|--|
| **Плюсы** | Любой дизайн (как danforge.ru); дашборды, графики; кроссплатформа. |
| **Минусы** | Electron тяжёлый (~150 MB); Tauri легче, но Rust toolchain; два слоя кода. |
| **Оценка** | 60–120 ч |

**Когда выбирать:** GUI как витрина бренда, планируется много экранов.

---

### 4. Web-only: Flask/FastAPI + браузер

**Суть:** `python app.py` → localhost:8787, UI в браузере.

| | |
|--|--|
| **Плюсы** | Красивый UI без Electron; легко шарить в LAN; тот же HTML/CSS что на сайте. |
| **Минусы** | Не «приложение в панели»; пользователь должен открыть браузер; нужен локальный сервер. |
| **Оценка** | 32–64 ч |

**Когда выбирать:** комфортно работать в браузере; не нужен exe.

---

### 5. Streamlit / Gradio

**Суть:** UI из Python-декораторов, без вёрстки.

| | |
|--|--|
| **Плюсы** | Очень быстро (1–3 дня); формы, логи, кнопки из коробки. |
| **Минусы** | Шаблонный вид; слабый контроль UX; мульти-клиент слева — костыльно. |
| **Оценка** | 16–24 ч MVP |

**Когда выбирать:** внутренний инструмент, не публичный продукт.

---

### 6. NiceGUI / Flet

**Суть:** Python описывает UI, рендер в webview или Flutter.

| | |
|--|--|
| **Плюсы** | Современнее Tkinter, один язык; Flet — Material Design. |
| **Минусы** | Моложе экосистема; exe менее предсказуем. |
| **Оценка** | 24–48 ч |

**Когда выбирать:** компромисс desktop + современный вид без Electron.

---

### 7. Консоль + Rich / Textual (TUI)

**Суть:** терминальный полноэкранный интерфейс.

| | |
|--|--|
| **Плюсы** | Минимум зависимостей; для power users. |
| **Минусы** | Не для «клиента на Kwork»; Windows cmd не любит. |
| **Оценка** | 16–32 ч |

**Когда выбирать:** только как доп. режим для себя.

---

### 8. VS Code / Cursor extension

**Суть:** панель в IDE, конфиги в workspace.

| | |
|--|--|
| **Плюсы** | Рядом с кодом виджета. |
| **Минусы** | Не для конечного покупателя виджета. |
| **Оценка** | 40+ ч |

**Когда выбирать:** только внутренний workflow DanForge.

## Сравнение для DanForge

| Вариант | Красота | Скорость внедрения | exe для клиента | Бренд DanForge | Рекомендация |
|---------|---------|-------------------|-----------------|----------------|--------------|
| CustomTkinter | ★★★ | ★★★★★ | ★★★★★ | ★★★ | **быстрый путь** |
| Qt (PySide6) | ★★★★ | ★★★ | ★★★★ | ★★★★ | долгосрочный desktop |
| Web local (FastAPI) | ★★★★★ | ★★★ | ★★★ | ★★★★★ | **лучший бренд** |
| Tauri + Python | ★★★★★ | ★★ | ★★★★ | ★★★★★ | если нужен именно app |
| Streamlit | ★★ | ★★★★★ | ★★ | ★★ | только MVP |
| Flet / NiceGUI | ★★★★ | ★★★★ | ★★★ | ★★★★ | компромисс |

## Рекомендация команды (на завтра)

### Этап A — 1–2 дня (если нужно «срочно лучше»)
**CustomTkinter:** тёмная тема, цвета DanForge, секции «Магазин / Яндекс / Слайдер / Запуск», иконки, прогресс при парсинге.

### Этап B — 1–2 недели (целевой продукт)
**Локальный web-дашборд (FastAPI + простой React или даже Jinja + Alpine):**
- экран «Клиенты»;
- карточка клиента + история `run.log`;
- кнопки тех же действий;
- упаковка: `start.bat` открывает браузер + поднимает сервер.

### Не рекомендуем сейчас
- полный Electron (избыточен);
- Streamlit как финал (слишком generic для Kwork-упаковки).
