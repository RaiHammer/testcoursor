## Задача 1: Фото из отзывов Яндекса (`.business-review-view__carousel`)

**Исполнитель:** Programmer  
**Приоритет:** высокий

### Проблема
Парсер v1.3.0 берёт аватар (`itemProp="image"`), но **не извлекает фото товаров/отзыва** из карусели `.business-review-view__carousel`.

### Что проверить
- разметка SSR: `img` внутри carousel, `background-image`, `data-src`;
- сколько фото на отзыв (0–N);
- стабильность URL (CDN Яндекса, срок жизни).

### Предлагаемая модель данных
```python
@dataclass
class Review:
    ...
    photo_urls: list[str] = field(default_factory=list)
```

### Цепочка
1. `parse_yandex_html` — regex/DOM по carousel;
2. `generate_liquid` — блок `df-reviews__photos` в слайде;
3. виджет — галерея или lightbox;
4. опция в config: `include_review_photos: true`.

**Оценка:** 6–10 ч (парсер + Liquid + виджет).

## Задача 2: «Читать полностью» без сворачивания

**Исполнитель:** Programmer  
**Приоритет:** средний

### Проблема
В `snippet.js` кнопка при клике добавляет `is-expanded` и **удаляется** (`btn.remove()`), обратного действия нет.

```javascript
// snippet.js ~206–209
btn.addEventListener('click', function () {
  textEl.classList.add('is-expanded');
  btn.remove();
});
```

### Решение
- не удалять кнопку;
- toggle: «Читать полностью» ↔ «Свернуть»;
- после сворачивания — `swiper.update()` для высоты слайда.

**Оценка:** 1–2 ч + тест в `widget/tests/`.
