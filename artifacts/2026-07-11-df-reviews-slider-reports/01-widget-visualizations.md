# Отчёт: варианты визуализации виджета отзывов

**Дата:** 2026-07-11  
**Автор:** Designer + Analyst (DanForge)  
**Проект:** `df_reviews_slider`  
**Статус:** предложения к обсуждению, без реализации

---

## Текущее состояние

Сейчас один режим — **горизонтальный слайдер на Swiper**:
- карточки одинаковой высоты в ряд;
- стрелки, точки, autoplay;
- обрезка текста + «Читать полностью»;
- аватар, рейтинг, источник, дата.

Это хорошо для главной: компактно, знакомый паттерн, не занимает много вертикали. Ограничение — все отзывы «в одной линии», фото из отзывов пока не показываются.

---

## Критерии выбора формата

| Критерий | Важность |
|----------|----------|
| Читаемость длинных отзывов | высокая |
| Показ фото к отзыву (Яндекс carousel) | высокая (запрос) |
| Работа на мобильных | критично |
| Настройка из inSales без кода | обязательно |
| Производительность (lazy load) | средняя |
| Уникальность для Kwork/продажи | средняя |

## Варианты визуализации

### 1. Слайдер (текущий) — оставить как режим по умолчанию

**Плюсы:** уже готов, предсказуем, мало места по высоте.  
**Минусы:** фото в карточке сложно вписать без роста высоты слайда.

**Доработка в том же режиме:**
- мини-галерея 1–3 фото под текстом;
- фикс «Свернуть» после «Читать полностью».

**Оценка:** 4–8 ч на фото + collapse.

---

### 2. Masonry / Pinterest-сетка

Карточки разной высоты в колонках (CSS columns или библиотека типа Masonry / CSS Grid `grid-auto-rows`).

**Плюсы:**
- естественно для отзывов разной длины;
- фото крупно внутри карточки;
- современный вид, хорошо для лендинга «социальное доказательство».

**Минусы:**
- на мобильном — 1 колонка, много скролла;
- без «автопрокрутки» — меньше динамики на главной;
- inSales: нужна настройка «колонок» (1 / 2 / 3).

**Рекомендация:** режим `layout: masonry`, колонки 2–3 на desktop, 1 на mobile.

**Оценка:** 12–16 ч (разметка, SCSS, JS фильтры, настройки).

---

### 3. Статическая сетка (равные карточки)

Grid 2×2 или 3×N, карточки одной высоты, текст clamp.

**Плюсы:** проще masonry, стабильная вёрстка, без Swiper.  
**Минусы:** длинный текст обрезается чаще; фото только превью.

**Рекомендация:** режим `layout: grid` для каталога/страницы «О нас».

**Оценка:** 8–12 ч.

---

### 4. Вертикальная лента (stack / timeline)

Отзывы столбиком, слева аватар и дата — как лента комментариев.

**Плюсы:** максимум читаемости, удобно с фото, хорошо для SEO (весь текст в DOM).  
**Минусы:** занимает много места на главной; нужен лимит «показать N» + «ещё».

**Рекомендация:** режим `layout: list`, опция `max_visible: 5`.

**Оценка:** 6–10 ч.

---

### 5. Карусель «один отзыв на экран» (hero testimonial)

Крупная цитата по центру, фото на весь блок, смена по таймеру.

**Плюсы:** премиальный вид, акцент на 3–5 лучших отзывах.  
**Минусы:** мало отзывов видно сразу; не подходит если нужно «70 отзывов».

**Рекомендация:** режим `layout: spotlight` + фильтр min_rating=5.

**Оценка:** 10–14 ч.

---

### 6. Бегущая строка (marquee)

Горизонтальный бесконечный скролл коротких цитат.

**Плюсы:** динамика, мало высоты.  
**Минусы:** плохо для длинного текста и фото; раздражает часть пользователей; хуже для accessibility.

**Рекомендация:** низкий приоритет, только как опциональный «декор».

**Оценка:** 6–8 ч.

---

### 7. Вкладки по источнику

«inSales» | «Яндекс» — переключатель без смены layout.

**Плюсы:** прозрачность источников (уже есть hide_*).  
**Минусы:** не замена layout, а дополнение.

**Рекомендация:** комбинировать с любым layout.

**Оценка:** 4–6 ч.

## Рекомендуемая продуктовая линейка

Не один виджет, а **один handle с переключателем layout** в `settings_form.json`:

```
layout: slider | masonry | grid | list | spotlight
```

**MVP на завтра/неделю (приоритет):**
1. **slider** — фикс collapse + фото в карточке (после парсера).
2. **masonry** — второй режим для продажи «премиум-вид».
3. **list** — для страницы отзывов целиком.

**Архитектура:** общий JSON/Liquid слайдов не меняется; меняются `snippet.liquid`, `snippet.scss`, `snippet.js` и ветка инициализации по `data-layout`.
