# Strategic Planning

## Когда применять

Пользователь хочет обсудить, а не сразу делать:
- «Давай обсудим...»
- «Стоит ли...»
- «Какие каналы...»
- «Проработай идею...»

## Workflow

1. **Уточни контекст** — 1–2 вопроса, если цель неясна
2. **Исследование** — при необходимости делегируй `analyst` (рынок, конкуренты, ЦА)
3. **Структурируй обсуждение:**
   - Проблема / возможность
   - Варианты (2–3 минимум)
   - Плюсы / минусы каждого
   - Рекомендация с обоснованием
4. **Не запускай Programmer** без явного перехода в операционный режим
5. **Зафиксируй результат**

## Куда сохранять

| Тип | Файл |
|-----|------|
| Новая идея | `knowledge/strategy/ideas-backlog.md` |
| Принятое решение | `knowledge/strategy/decisions/YYYY-MM-DD-{slug}.md` |
| Обновление roadmap | `knowledge/strategy/roadmap.md` |

## Формат решения

```markdown
# Решение: {название}

**Дата:** YYYY-MM-DD
**Контекст:** ...
**Решение:** ...
**Альтернативы:** ...
**Следующий шаг:** ...
```

## Переход в операционный режим

Когда идея созрела, предложи:
> «Идея проработана. Перевести в задачу? Создам task-id и запущу конвейер.»
