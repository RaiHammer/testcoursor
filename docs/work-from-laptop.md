# Работа с ноутбука / другого ПК

Как продолжить работу над «Личным джарвисом» не с этого Desktop, а с ноутбука или другой машины.

Репозиторий (private): [https://github.com/RaiHammer/testcoursor](https://github.com/RaiHammer/testcoursor)

## Что синхронизируется, а что нет

| Что | Через git / GitHub | Примечание |
|-----|--------------------|------------|
| Файлы проекта (`knowledge/`, `artifacts/`, код, правила) | Да | `git clone` / `git pull` / `git push` |
| Чаты Cursor на этом Desktop | **Нет** | История чатов **не** едет вместе с репозиторием и не «подхватывается» автоматически на другом устройстве |

Итого: **файлы — через приватный clone**, **этот чат с Desktop — не синхронизируется**. На ноутбуке открываете репозиторий и начинаете **новый** чат, подключая нужный контекст через `@`.

## Чеклист: сегодня Desktop → завтра ноутбук

1. **На Desktop сегодня:** закоммитить и запушить актуальные изменения (`git push`), чтобы на GitHub была свежая копия.
2. **На ноутбуке:** клонировать репозиторий (если ещё нет) или сделать `git pull`.
3. **Аккаунты:** войти в **тот же GitHub** (доступ к private repo) и **тот же Cursor**.
4. **В Cursor:** открыть папку клона как workspace.
5. **Новый чат:** не ждать «того же» Desktop-чата — создать новый и явно подтянуть контекст, например:
   - `@artifacts/...` — нужные артефакты задачи;
   - `@knowledge/...` — база знаний, roadmap, решения;
   - при необходимости `@AGENTS.md`, `@README.md`.

## Клонирование (кратко)

```bash
git clone https://github.com/RaiHammer/testcoursor.git
cd testcoursor
```

Откройте эту папку в Cursor (**File → Open Folder**). Для private repo нужна авторизация GitHub (HTTPS + credential / token, или SSH-ключ, привязанный к аккаунту с доступом).

## На ноутбуке после правок

Перед тем как снова сесть за Desktop (или наоборот):

```bash
git status
git add …
git commit --trailer "Co-authored-by: Cursor <cursoragent@cursor.com>" -m "…"
git push
```

На другой машине — `git pull`, затем новый или продолженный локальный чат с `@` на обновлённые файлы.
